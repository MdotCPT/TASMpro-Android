# TASMpro v1.6.20 RC1 — Live trade lists

- Trades tab automatically groups existing snags by assigned trade across all projects.
- Opening a trade defaults to all plots, with the existing selectable plot and status filters for preview, PDF and email.
- Removed the separate Create Trade Report and Save Trade Report workflow.
- Purging a trade list hides it from the Trades tab without deleting source snags or photographs. Hidden lists can be restored.
- Purge All hides all current trade lists; restoration brings them back.
- Preserves prior backup import, project report, and Android sharing implementations.

Test on-device before using with critical records.
