# TASMpro v1.6.17 RC1 — Reports Refinement

- Tap Report Summary on a plot report to open a scrollable snag register.
- Edit snag description, trade and status; complete/reopen or permanently delete a snag with confirmation.
- Choose any existing photo on a snag as the persistent project cover thumbnail. If removed, the library falls back to another available photo.
- Report status filter now offers outstanding, completed and all snags.
- Trade report plot selection now honours checked plots; select any combination, and save a trade report entry explicitly.
- Trade reports list only saved report shortcuts. Purge one or all without deleting master plot snags or photographs.
- Removed the bin emoji from Delete Project.

## Important

This release changes the saved trade-report list model. Existing dynamically generated trade lists are no longer automatically shown as saved reports. Create a trade-specific report from any plot's report options, choose its plots and save it to the Trades library. This does not affect master snags.

## Validation

JavaScript syntax and ZIP integrity checked. Android APK compilation and on-device behaviour not yet tested. Test against disposable plots before relying on destructive actions.
