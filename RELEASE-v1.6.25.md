# TASMpro v1.6.25 RC1

- Plot-specific report options no longer display the Select plots checklist or status dropdown.
- Plot report selection is bound to the plot opened, not to stale cross-plot checkbox state.
- Plot reports default to outstanding snags for that plot only.
- Trade report project checkboxes and trade-specific filtering remain unchanged.
- No database migration or deliberate changes to saved snag/photo data.

Requires Android build and on-device verification before release.
